REPORTFLOW PRO v0.1

What this prototype does:
- Loads built-in sample company data
- Uploads CSV files
- Maps CSV columns to ReportFlow fields
- Displays KPIs, revenue trend, filters, and operational table
- Automatically flags overdue work, high-hour jobs, and low-revenue jobs
- Lets you configure flagging thresholds
- Exports filtered records to CSV
- Generates a printable / PDF-ready executive report using the browser print dialog

How to run:
1. Open index.html in Chrome or Edge.
2. Use the sample dashboard immediately, or open Data Import and upload a CSV.
3. Map the columns and click Import Data.
